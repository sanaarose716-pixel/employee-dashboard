# Employee Dashboard

A React employee dashboard built using Vite.

## Features
- Home page
- Employee directory fetched from an API
- Employee form with Name, Designation, Location, and Salary fields

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Vite

## Run Locally
1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`

## API
Employee data is fetched from JSONPlaceholder:
https://jsonplaceholder.typicode.com/users
